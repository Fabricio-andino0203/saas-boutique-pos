# Comentarios de uso (fricciones)

Aquí se anota, durante la primera semana real y después de cada capacitación, **dónde se trabó alguien**: lo que no entendió, lo que tardó, lo que hizo mal sin querer. Es la fuente de las mejoras de la próxima fase (`docs/ROADMAP.md`). Una fila por cosa; sin culpables: si la persona se equivoca, el sistema o el manual no lo explicó bien.

**Cómo anotar:** fecha, quién (rol, no hace falta el nombre), qué intentaba hacer, qué pasó y cuánto se tardó. Si hay una captura, guárdala en `docs/manual/img/` y enlázala.

| Fecha | Rol | Qué intentaba | Qué pasó | Tiempo perdido | Idea de mejora | Estado |
| --- | --- | --- | --- | --- | --- | --- |
| _ejemplo_ 2026-11-02 | Cajero | Dar el cambio de un pago mixto | No vio la línea "Falta" y cobró de menos | 2 min | Resaltar "Falta" en rojo hasta que sea 0 | Pendiente |
|  |  |  |  |  |  |  |

## Prueba de aceptación del manual (criterio de la Fase 6)

> Una persona **no técnica** completa el flujo de venta usando **solo el manual de 1 página** ([cajero.md](manual/cajero.md)).

Cómo hacerla: siéntate con alguien que nunca haya usado el sistema, dale **solo** el manual impreso, pídele que abra su caja, haga una venta en efectivo con una prenda con talla y color y cierre la caja, y **no le ayudes** (anota lo que preguntaría). Registra el resultado:

| Fecha | Persona (rol) | ¿Completó la venta sola? | Dónde preguntó o se trabó | Minutos |
| --- | --- | :-: | --- | --: |
|  |  |  |  |  |

Esta prueba **no la puede hacer quien programó el sistema**: necesita una persona real de la tienda.
